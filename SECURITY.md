# Security Policy

## Reporting a vulnerability

Please do not disclose suspected vulnerabilities in public issues, pull requests, or discussions.

Use GitHub's private vulnerability reporting feature from this repository's **Security** tab if it is available. If private reporting is not enabled, contact the repository maintainer through their GitHub profile to arrange a private report.

Include the affected commit or release, the security impact, minimal reproduction steps, and any known mitigations. Please avoid including real credentials, personal data, or third-party secrets in the report.

## Scope and expectations

Please distinguish a reproducible security impact from a hardening suggestion or a theoretical concern. This project does not promise a particular response time, service level, or bounty unless a separate published policy says otherwise. Coordinated disclosure is appreciated; please allow the maintainer a reasonable opportunity to investigate before public disclosure.
